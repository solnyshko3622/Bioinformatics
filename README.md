# Задание 1

## Фенотип

Я выбрала фенотип **дальтонизм**. Это нарушение цветового зрения, при котором человек не различает красные и/или зелёные цвета. Оно связано с дефектами в колбочках сетчатки глаза, отвечающих за восприятие длинноволнового (красного) и средневолнового (зелёного) света.

---

## Гены человека, ассоциированные с данным фенотипом

- [**OPN1LW**](https://www.ncbi.nlm.nih.gov/gene/5956) — отвечает за восприятие **красного** цвета  
- [**OPN1MW**](https://www.ncbi.nlm.nih.gov/gene/2652) — отвечает за восприятие **зелёного** цвета  

---

## Последовательности генов у человека и модельного организма

В качестве модельного организма выбран **Nomascus leucogenys** (*белощёкий гиббон*).

### 🔸 Ген **OPN1LW**
- [Человек (Homo sapiens)](https://www.ncbi.nlm.nih.gov/gene/5956)
- [Гиббон (Nomascus leucogenys)](https://www.ncbi.nlm.nih.gov/gene/115833325)

### 🔸 Ген **OPN1MW**
- [Человек (Homo sapiens)](https://www.ncbi.nlm.nih.gov/gene/2652)
- [Гиббон (Nomascus leucogenys)](https://www.ncbi.nlm.nih.gov/gene/100595592)
