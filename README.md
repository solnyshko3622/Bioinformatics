## Ген
Я выбрала ген [FOXP2 forkhead box P2 [ Homo sapiens (human) ]](https://www.ncbi.nlm.nih.gov/gene/93986). Этот ген необходим для правильного формирования речевых и языковых областей мозга в период эмбриогенеза и, возможно, участвует в различных биологических путях и каскадах, которые в конечном итоге могут влиять на развитие речи.
