## Фентоип

Я взяла фенотип - дальтонизм. Это заболевание, связанное c нарушением цветового зрения, при котором человек не различает красные и зелёные цвета. Происходит из-за нарушений в работе колбочек сетчатки глаза, отвечающих за восприятие длинноволнового (красного) и средневолнового (зелёного) света.
